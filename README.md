# 서울대학교 미술대학 80주년 웹사이트

현재 테스트 사이트의 전체 소스입니다. 별도 패키지 설치나 빌드가 필요 없습니다.

## 실행
압축을 풀고 index.html을 브라우저에서 여세요.
휴대폰에서 테스트하려면 네 파일을 같은 폴더 구조로 정적 웹 호스팅에 올린 후 HTTPS 주소로 접속하세요.
촬영 버튼 동작은 기기와 브라우저에 따라 달라집니다.

## 파일
- index.html: 랜딩 화면, 궤적만들기 화면, 한영 문구와 크레딧
- styles.css: 모바일 레이아웃, 흰 배경, 연한 회색 둥근 버튼
- core.js: 고정 색상과 원본 SVG, 색 감지 및 화살표 경로 규칙
- app.js: 화면 이동, 사진 입력·분석, PNG 다운로드

## 현재 설정
- 색 면적 기준 3% (core.js의 settings.low.area = .03)
- 위치·회원 확인 없음
- 사진은 브라우저 내부에서 처리되며 서버에 업로드되지 않습니다.
- 3% 이상인 색이 없으면 가장 많이 검출된 색 1개를 사용합니다. 검출색이 없으면 기본 주황색을 표시합니다.
- 학교 이메일은 아직 주소가 지정되지 않은 텍스트입니다. index.html의 크레딧에서 원하는 mailto 링크로 바꿀 수 있습니다.
- 다운로드 형식: PNG (1260 × 1080)

이 압축에는 호스팅 계정 정보나 인증 정보가 포함되어 있지 않습니다.
